# #25 Phone: list clears the floating composer, and the task sheet shows its task
Status: done
PR: (see branch issue/25-phone-list-padding)
Summary: On phones the docked composer's height is measured into `--dock-h` on `<html>`; the list's bottom padding (`--dock-clear`) and the undo toast's position are derived from it, so the last row and the toast clear the composer however tall it grows; the phone task sheet now opens with the task title.

## What changed
- src/components/TaskInput.tsx: a ResizeObserver (border-box, phone only) writes the dock's height to `--dock-h` on `document.documentElement`; removed on unmount or when leaving phone width.
- src/styles/theme.css: `:root { --dock-h: calc(86px + safe-area) }` at ≤480px as the pre-measure fallback (the idle bar); `--dock-clear` is now `--dock-h + --space-4` (was a fixed 104px + safe area).
- src/components/UndoToast.module.css: phone toast `bottom: --dock-h − --space-6 (dock fade) + --space-2`, i.e. 8px above the composer card; same as before when idle, and it now rises above an expanded composer instead of sliding under it.
- src/components/TaskMenu.tsx/.module.css: on phones (`useIsPhone`) an `h2` with the task title, 15px/600, clamped to 2 lines, above Difficulty. Read-only; renaming stays in the row's title editor.
- src/components/Notes.test.tsx: `rowOf` picks the title inside a row, since the exiting sheet now repeats it.

## Checked
- Playwright at 375×812, light and dark, against emulators: idle dock 86px, last row ends 14px above the dock; toast bottom 8px above the card; composer with text → dock 164px, list padding 180px. Sheet shows "Task number 3".

## Notes for future agents
- The built-in browser pane, when hidden, runs no rendering frames (no rAF, no ResizeObserver callbacks). Use the Playwright MCP for layout checks.
