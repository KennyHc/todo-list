# #44 Phone view: bigger touch targets, better spacing and polish at 375px
Status: done
PR: #47
Summary: New `--tap` (44px) and `--tap-inset` tokens; `(pointer: coarse)` blocks in 21 component stylesheets give every flagged control a 44×44 hit area (hit boxes for icons and links, 44px height for segments, picks, inputs and dialog buttons), meta rows make room for the tags' hit areas, the composer popovers span the phone, and 320px no longer scrolls sideways; desktop rules are untouched.

## What changed
- src/styles/theme.css: `--tap: 44px`; `--tap-inset: min(0px, (100% - --tap) / 2)`. Used as `::after { inset: var(--tap-inset) }` on a positioned control, it grows the hit area to ≥44 on both axes, centred, and is 0 for bigger controls.
- Hit boxes: dialog close (AiModal), Filter (TagFilter, now 36px like Search), Clear date, the editor chip's dot/×, the colour swatches, Import links and steps, the Delete account "Export a backup first" link, a row's note button.
- 44px tall: difficulty/repeat segments, date picks and field, tag field and suggestions, AiModal and ConfirmDialog buttons (the Confirm buttons share the width on a phone), Copy-for-AI chips, palette results, Today's "Plan your day". Theme toggle and view options are 44px wide.
- TaskItem (phone, coarse): the title's hit area covers the first-line band. A meta row gets 8px under the title and 20px bottom padding, so a tag's hit area (set through `--tag-hit-inset` on `.tail`) runs from the title's last line to the row's bottom edge and never covers the title. `.tail` uses `overflow-x: clip` (was `hidden`, which clipped those hit areas to the 16px line).
- BreakdownNudge: its wrapper clips (height animation), so the line itself is 44px tall.
- Popover: anchored popovers on coarse phones get `min-width: 100vw - 16px`; Popover.tsx places them by measured width.
- ≤359px: date picks go 2×2; with five views the view options drop to 40px and the toolbar gaps to 4px so 320px fits.

## Tried and rejected
- Symmetric 44px tag hit (`--tap-inset`): it covered the bottom 6px of the title, so tapping the title could filter by tag.
- A shared `composes:` class: it would set `position` from another file and fight component rules.

## Notes for future agents
- Measure hit areas with `elementFromPoint`, not boxes plus pseudo-element insets: `overflow: hidden` ancestors and later siblings silently shrink them.
- Left alone: Week view (#28), undo toast (#42), sync indicator (#24); the History "Edit" button loses its top 4px under the sticky toolbar (pre-existing).
- The built-in browser pane pauses framer animations while hidden; front the tab before screenshots.
