# #18 Remove the stray Tab stop in every row's checkbox
Status: done
PR: pending
Summary: Moved `whileTap` from the inner `motion.span` to the checkbox `<button>` (now a `motion.button`), so the checkbox is one Tab stop; added a component test for it.

## What changed
- src/components/Checkbox.tsx: framer-motion gives any element with `whileTap` a `tabindex="0"`,
  so the inner box span was an unnamed Tab stop in every row. The button now carries
  `whileTap={{ scale: 0.85 }}` (same pattern as the chevron in TaskItem); the box keeps its
  check/uncheck `animate`. `data-press="off"` stays, so the global CSS press doesn't double up.
- src/components/Checkbox.test.tsx: asserts exactly one focusable element (the role=checkbox
  button), checked and unchecked. Fails on the old code (2 focusable elements).

## Tried and rejected
- CSS `:active` scale on `.box`: framer's inline `transform` from `animate` would override it.
- `tabIndex={-1}` on the span: leaves a gesture handler on a non-control; moving it is cleaner.

## Notes for future agents
- Any `whileTap`/`whileFocus` on a non-focusable motion element makes it focusable. Put
  gestures on the real control.
- Local e2e couldn't run here: Docker holds 8080 (Firestore emulator port). CI runs it.
