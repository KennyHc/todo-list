# #8 Week view interactions: drag between days, add into a day
Status: done
PR: #17
Summary: Week rows drag between days (mouse grip, touch long-press, Tree's sensors) with a "Moved … · Undo" toast, planned rows move `plannedFor`; each day has a "+" that opens the composer set to that day; the day header opens By deadline at that date; `[`/`]` move the selected row a day.

## What changed
- src/lib/week.ts (+ test): `weekDropMove` (drop: due row → dueDate, planned row → plannedFor), `weekStepMove` (`[`/`]`), `firstDueFrom` (header target). Pure, `today` passed in.
- store/tasks.ts `moveToDay(id, {field, date})`: one undo, label from `rescheduleLabel`. No data-model change.
- hooks/dragSensors.ts: MousePenSensor + MOUSE/TOUCH_ACTIVATION moved out of TaskList so Tree and Week share them (4px; 350ms/5px long-press).
- WeekView: own DndContext, `pointerWithin`, rows `useDraggable` (open tasks only), days `useDroppable` (`data-over` tint), DragOverlay = DragPreview, useDragStore for dimming. Grip label "Move X" (`RowDrag.verb`).
- "+": `ui.composerDay` → TaskInput `dayDue`. Order: toolbar pick > date/repeat in text > the day. Cleared on submit, on "Clear due date", or on blur with nothing typed.
- Day header: weekday+date is a button → By deadline, first open task due that day (else the next later) focused + flashed; the focused row scrolls itself into view.
- `[`/`]` (Week, row selected): due date ±1 if due this week, else the plan; the week follows past Sun/Mon. Listed in the shortcuts sheet.
- Tests: week.test.ts, WeekView.test.tsx ("+", header, keys), tasks.test.ts, useHotkeys.test.ts, e2e/week.spec.ts drag case (mouse on desktop, CDP long-press on mobile).

## Tried and rejected
- Scrolling By deadline to a date header: it has buckets (Today, This week…), not dates, so the header selects the first task due on/after the day instead.
- Plans moved before today (drop or `[`): ignored, since an open past plan rolls over to today and would not visibly move.

## Notes for future agents
- A task on two days (due + planned) dims both rows while one is dragged: activeId is a task id.
- `[`/`]` act on the task, not a row: due date wins when it is due that week.
- e2e: app hardcodes emulator ports 9099/8080; here 8080 was Docker and 9099 another session's emulator, so e2e ran on own emulators (9199/8180) with an uncommitted port patch. Worth an issue: env-configurable emulator ports.
