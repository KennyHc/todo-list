# #20 Active tag filter chip collapses to 0 px and pushes Filter out of the column
Status: done
PR: #36
Summary: Moved the active `#tag` chip out of the toolbar row into a new "Filtered by #tag · Clear" line under it (rendered by ViewToolbar, so every view gets it, History included); the toolbar row is now views + Search + Filter only and fits the column from 375 to 1280 px.

## What changed
- `TagFilter.tsx`: new `FilterBanner` (role="status", chip + Clear button); removed the chip from `TagFilter`.
- `TagFilter.module.css`: dropped the `.filter > span` shrink rules that let the chip collapse; banner styles copy `OverdueNudge`'s line.
- `ViewToolbar.tsx`: renders `<FilterBanner />` under the bar.
- `TagFilter.test.tsx`: chip visible, Clear clears the filter and hides the banner; banner in History.

## Tried and rejected
- Keeping the chip in the toolbar row with a min-width: with five labelled views the row is already
  648 px at 1280 (Filter ends exactly at the column edge) and ~343 px at 375, so there is no room.

## Notes for future agents
- Measured in a local harness (App without AuthGate): Filter's right edge == column edge at 375,
  768 and 1280 px with all five views; no horizontal page scroll. A long tag ellipsizes in the banner.
- The chip in the banner has no ×; "Clear" is the one clear action. The Filter button keeps its
  blue active colour.
- Local e2e not run (Docker holds 8080); this change is covered by the component test.

## Open questions

  without wrapping the row; the banner sits directly under it instead.
