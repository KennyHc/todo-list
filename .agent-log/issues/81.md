# #81 UI polish: a refined, premium visual pass (tokens, type, surfaces, motion)
Status: needs review
PR: #83
Summary: New type, weight, tracking, radius, elevation and scrim tokens in theme.css replace every raw font-size/weight/tracking/radius in 49 module stylesheets; light accent deepened to ink blue #4a69e2 (white check marks), segmented controls share one raised `--thumb`, tints replace solid difficulty fills, softer focus halos, frosted toast, larger sheet radius, and reduced motion zeroes CSS durations and press scale. Visual only.

## What changed
- theme.css: scales `--fs-2xs…3xl` (11/12/13/14/14.5/15/16/24/28), `--fw-regular/medium/semibold/bold` (450/500/580/660), `--track-display/tight/snug/wide/caps`, `--r-xs/sm/md/lg/xl/full` (4/6/10/14/20/999), `--thumb`, `--scrim`, `--danger-fill`; layered `--shadow-*`; slightly cooler neutral greys. Reduced motion: `--dur-fast/base/slow` 1ms, `--press-scale` 1.
- Light `--accent` #7c9cf0 → #4a69e2, `--check-ink` → white (4.76:1), `--accent-ink` #3955c4, `--muted` #5c6370. Dark: `--muted` #8b92a0 (4.5+ on accent-soft), `--elevated` #1d2027.
- Mapping (scripted): half-pixel sizes round to the nearest step (12.5→13, 11.5→12, 13.5→14, 10/10.5→11, 26/30→28, 17→16); 400/450→450, 550/600→580, 650/700→660; 3–5px radii → `--r-xs`.
- ViewSwitch/ThemeToggle: nested radii `calc(var(--r-md) - 2px)`; thumb `--thumb` (dark thumb is now lighter than its track, not darker).
- RepeatPicker: selected = raised thumb (was accent box). DifficultyPicker: filled = accent tint + accent-ink number. DatePicker picks: hairline border, soft focus halo.
- Composer focus: accent-soft halo instead of the 3px ring. Popover radius `--r-lg`; sheets `--r-xl`. Undo toast frosted (90% + blur). Empty-state icon `--accent-ink`.
- ConfirmDialog / DeleteAccount destructive buttons: `--danger-fill` (#fff on #e5484d was 3.9:1, now 4.78).
- Screenshots (before | after): `.agent-log/shots/81/`.
