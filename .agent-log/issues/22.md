# #22 Use the quick-add parser in subtask input and title editing
Status: done
PR: #54
Summary: The inline title editor (row "+", menu "Add subtask", "Add subtasks →" and renaming) now runs the draft through `parseQuickAdd` and shows the composer's chips under the input; saving applies only what the text sets (`quickPatch`), so renaming keeps the task's other fields.

## What changed
- src/lib/quickEdit.ts (+ test): `quickPatch(task, parsed)` → TaskPatch. Typed tags are added to the
  task's tags; typed date / start / difficulty replace; a typed repeat goes through `repeatPatch`
  (same as the Repeat menu, so #40's spawn/reopen rules in `toggle` apply unchanged). A tag-only
  line keeps the current title.
- src/components/QuickChips.tsx (+ css): the composer's chips (QuickChip / TagChip) as a plain
  list, no motion; mouse down is prevented so dismissing a chip doesn't blur and save.
- src/components/TitleEditor.tsx: parses the draft, renders `QuickChips` after the input (the
  title line wraps, so they sit on their own line), saves via one `save()` for Enter, Tab, blur
  and the phone ⋯. A later start date shows the composer's "Hidden until …" notice.
- src/components/TitleEditor.test.tsx: row "+", "Add subtasks →", dismissing a chip, rename
  keeps/replaces fields, old phrases left alone.
- TaskInput.tsx (main composer), `parseQuickAdd` vocabulary and TaskItem.tsx are untouched.

## Tried and rejected
- Moving the composer's chip JSX into a shared component: would edit TaskInput.tsx, which #49 is
  changing; the composer was also meant to stay unchanged.

## Notes for future agents
- Phrases already in the saved title start out dismissed (ignore set = tokens of the initial
  title), so "Meeting on friday" isn't turned into a date by editing it. Keys are `start:raw`,
  so typing before such a phrase shifts it and it gets recognised again (shown as a chip).
- `npm run test:e2e` can't start on this machine while 8080 (Docker caddy) or 9099 is taken; the
  app hard-codes both ports in src/lib/firebase.ts and src/lib/firestore.ts.
