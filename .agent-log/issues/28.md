# #28 Week view polish: alignment, past days, overdue
Status: done
PR: pending
Summary: At ≥1024 the week range is centred over the grid (under the centred page header); past days are muted cards with a quiet date; an open overdue row in Week shows Tree's red due pill; "Today" is only rendered off the current week (placed before the arrows so they don't move); a drop that moves a task empties the drag live region, so Undo no longer leaves "Dropped … on <day>" behind.

## What changed
- WeekView.module.css: `.bar` is a `1fr auto 1fr` grid from 1024px (range in col 2, nav right). `.day[data-past]` gets `--bg` and no shadow from 481px (phones have no cards), its date `--muted`. Removed `.todayBtn:disabled`.
- WeekView.tsx: DayRow passes `section` 'today' only when the row isn't overdue, so an overdue due row shows the full DuePill (red, `--danger-text`), same as Tree. Today button rendered only when `start !== current`, first in the nav group.
- Announcements `onDragEnd`: returns '' when `weekDropMove` gives a move (the undo toast's "Moved … to Thu, Nov 5" says it); otherwise "… was dropped without moving."
- WeekView.test.tsx: Today hidden/shown; past day flag + overdue pill (clock pinned to Tue 20 Oct 2026).

## Tried and rejected
- Keeping the 648px page column for the bar: then it doesn't line up with the grid, which the issue asks for.
- Hiding Today with `visibility: hidden`: leaves an odd gap; moving it before the arrows keeps them still without one.
- Clearing dnd-kit's announcement on Undo: dnd-kit has no API for it; `announce('')` from onDragEnd works since only null/undefined are ignored.
