# #50 Undo history: ⌘Z keeps working after the toast leaves
Status: done
PR: #55
Summary: The task store keeps a 20-step undo history (`past`) and a redo list (`future`); ⌘Z / Ctrl+Z steps back through it with or without the toast, ⇧⌘Z / Ctrl+Y redoes, text fields keep their own undo; the history is emptied on reset (sign-out, account switch) and trimmed to the toast's entry when remote content arrives.

## What changed
- `src/store/tasks.ts`: `past`/`future` beside `undo` (the toast). `undoEntry` pushes and shows the toast; new `quietEntry` pushes without a toast for add, `update` (not collapse-only, not the first edits of a row just added), indent and outdent. `undoLast` steps back one, `undoToast` steps back to before the toast's action, `redoLast`. Restores are plain `set`s, so sync diffs them like any edit.
- `src/components/UndoToast.tsx`: the key handler is always on (was only while the toast showed); toast button and palette's Undo call `undoToast`.
- `src/lib/shortcuts.ts`: "Redo ⇧⌘Z" under General.
- Tests: store history (depth, redo, reset, hydrate, drafts), toast keys, auth reset clears `past`/`future`.

## Tried and rejected
- Stacking only the toasted actions: snapshots restore the whole tree, so undoing an older entry would silently delete tasks added or renamed since. Hence quiet entries.
- Clearing history on every remote change, toast included: would change #30's toast behaviour; kept the toast entry instead.

## Notes for future agents
- An abandoned empty draft's quiet "Added" step is dropped on its removal, so ⌘Z never "does nothing".
- `hydrate` with tasks/rootIds/history/tagColors drops all steps but the toast's; settings-only hydrate keeps them.
- Pre-existing, not fixed: the toast's Undo restores a full snapshot, so a remote edit that lands during the 8 s window is reverted too. Worth an issue if multi-device use grows.

## Open questions
- ⌘Z now undoes adds, title edits and indents too (quietly). If that should stay toast-only, the history can't go deeper safely without per-action patches.
